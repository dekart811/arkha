# Tastenkürzel

Dies sind Arkhas übliche Tastenkürzel. Sie können sie ändern und auch anderen Aktionen Tastenkürzel geben, unter **Einstellungen → Tastatur** (siehe [Arkha anpassen](customizing.md#tastenkürzel)); **Hilfe → Tastenkürzel** (<kbd>Strg</kbd>+<kbd>F1</kbd>) zeigt sie, wie sie gerade sind.

## Maus

| Aktion | So geht’s |
|---|---|
| Einen Ordner in einem neuen Reiter öffnen | Mit der mittleren Maustaste darauf klicken |
| Einen Reiter schließen | Mit der mittleren Maustaste darauf klicken |
| Kopieren, verschieben oder beim Ablegen wählen | Mit gedrückter <kbd>Strg</kbd>-, <kbd>Umschalt</kbd>- oder <kbd>Alt</kbd>-Taste ziehen |
| Zoomen | <kbd>Strg</kbd> und das Mausrad |
| Zurück und vor | Die Zurück- und Vor-Taste der Maus |
| Automatisch rollen | Mittelklick auf eine freie Fläche |
| Ein Objekt finden | Den Anfang seines Namens tippen |

## Navigation

| Aktion | Tasten |
|---|---|
| Zurück | <kbd>Alt</kbd>+<kbd>←</kbd>, <kbd>Zurück</kbd> |
| Vor | <kbd>Alt</kbd>+<kbd>→</kbd>, <kbd>Vor</kbd> |
| Übergeordneten Ordner öffnen | <kbd>Alt</kbd>+<kbd>↑</kbd>, <kbd>Rücktaste</kbd> |
| Persönlicher Ordner | <kbd>Alt</kbd>+<kbd>Pos1</kbd> |
| Ort eingeben | <kbd>Strg</kbd>+<kbd>L</kbd> |
| Nach Dateien suchen | <kbd>Strg</kbd>+<kbd>F</kbd> |
| Neu laden | <kbd>F5</kbd>, <kbd>Strg</kbd>+<kbd>R</kbd> |
| Abbrechen (Suche oder Ortsleiste schließen) | <kbd>Esc</kbd> |

## Öffnen

| Aktion | Tasten |
|---|---|
| Öffnen | <kbd>Strg</kbd>+<kbd>O</kbd>, <kbd>Alt</kbd>+<kbd>↓</kbd> |
| In neuem Reiter öffnen | <kbd>Strg</kbd>+<kbd>Eingabe</kbd> |
| Im Terminal öffnen | <kbd>F4</kbd> |

| Aktion | Tasten |
|---|---|
| Neuer Ordner | <kbd>Strg</kbd>+<kbd>Umschalt</kbd>+<kbd>N</kbd> |

| Kopieren | <kbd>Strg</kbd>+<kbd>C</kbd> |
| Einfügen | <kbd>Strg</kbd>+<kbd>V</kbd> |

| Verknüpfung anlegen | <kbd>Strg</kbd>+<kbd>M</kbd> |

| Endgültig löschen | <kbd>Umschalt</kbd>+<kbd>Entf</kbd> |
| Eigenschaften | <kbd>Alt</kbd>+<kbd>Eingabe</kbd>, <kbd>Strg</kbd>+<kbd>I</kbd> |
