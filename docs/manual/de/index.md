# Arkha-Handbuch

Arkha ist eine Dateiverwaltung: Sie zeigt die Dateien und Ordner auf Ihrem Rechner, auf eingesteckten Laufwerken und auf Servern, und mit ihr können Sie sie öffnen, kopieren, verschieben, umbenennen und löschen. Sie funktioniert ähnlich wie Caja, die Dateiverwaltung von MATE, und teilt mit ihr Lesezeichen, Notizen, Embleme und Vorschaubilder.

Dieses Handbuch erklärt, was Arkha kann und wo Sie es finden. Drücken Sie in Arkha <kbd>F1</kbd>, um es zu öffnen.

6. [Suchen und Auswählen](search.md)
7. [Umbenennen](renaming.md): ein Objekt oder viele auf einmal
