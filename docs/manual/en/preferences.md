# Preferences

**Edit → Preferences** opens Arkha's settings, in pages listed on the left. Changes apply at once; there's nothing to save.

## Views

- **Default View:** the view new folders open in, how they're sorted, and whether folders come first.
- **Individual Folders:** whether each folder remembers its own view and sorting, and **Forget All** to make every folder use the defaults again.
- **Zoom:** each view's zoom level, and the sizes Zoom In and Zoom Out step through.
- **List View:** whether the list shows icons beside the names.

## Behavior

- **Opening:** single click to open items, instead of a double-click.
- **Tabs:** where new tabs go.
- **Split View:** let the pane under the mouse pointer take the keys and menus, after it rests there for a moment you set.
- **File Operations:** show copies and moves in a window of their own, instead of the button in the location bar.
- **Trash:** ask before moving files to the trash.
- **Search:** whether a new search also looks in the subfolders (see [Searching and selecting](search.md#only-this-folder)).
- **Other Programs:** let programs that "show a file in its folder" start Arkha when it isn't running.
- **Scrolling:** a middle-click on empty space autoscrolls.

## Display

- **Language:** Arkha's language (English or German), or the system's. Applies the next time Arkha starts; GTK's own dialogs follow it.
- **Files:** show hidden and backup files, alternating row colors in the list view and in Rename All, file sizes in IEC units (KiB, MiB, GiB, counted in 1024s, instead of kB, MB, GB), and how dates look: informal ("Today 14:05"), your language's, or ISO (2026-11-20 14:05).
- **Icon Captions:** what shows under the names in the icon view.
- **Window:** which bars show, whether the status bar says how many items are hidden, whether the tab bar shows with one tab, text on the toolbar buttons, and which buttons are beside the path bar.
- **Location Bar:** always show the location as text instead of buttons.

## List Columns

Which columns the list view shows, and their order.

## Previews

- **Text Files:** whether a text file's icon shows its first lines (at bigger sizes).
- **Other Previewable Files:** thumbnails, up to which file size, and your own thumbnailers (see [Making Arkha yours](customizing.md#your-own-thumbnailers)).
- **Folders:** whether folders show how many items they hold.
- **Media Info:** the Media Info tab in Properties, and for which kinds of files.
- **Info Panel:** the cover file names, and what the panel shows for several items and for folders without a cover.

Thumbnails, text in icons and item counts can each be shown **always**, for **local files only** (not on network places and phones), or **never**.
