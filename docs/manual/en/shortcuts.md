# Keyboard shortcuts

These are Arkha's usual shortcuts. You can change them, and give other actions shortcuts too, in **Preferences → Keyboard** (see [Making Arkha yours](customizing.md#keyboard-shortcuts)); **Help → Keyboard Shortcuts** (<kbd>Ctrl</kbd>+<kbd>F1</kbd>) shows them as they are now.

## Mouse

| Action | Do |
|---|---|
| Open a folder in a new tab | Middle-click it |
| Close a tab | Middle-click it |
| Copy, move, or choose when dropping | Drag with <kbd>Ctrl</kbd>, <kbd>Shift</kbd> or <kbd>Alt</kbd> held |
| Zoom | <kbd>Ctrl</kbd> and the mouse wheel |
| Back and forward | The mouse's back and forward buttons |
| Autoscroll | Middle-click on empty space |
| Find an item | Type the start of its name |
